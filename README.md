# 🚌 Guia do Busão

Bem-vindo ao repositório do **Guia do Busão**! Este é o projeto do curso Dev Full Stack. Nosso objetivo é criar uma aplicação web completa (Frontend + Backend + Banco de Dados) para ajudar usuários a encontrarem rotas, horários e conexões de ônibus.

---

## 👥 Equipe
Somos 11 membros, divididos em três squads (subgrupos) focados:

*   **🎨 Frontend:** Responsáveis pelo layout, responsividade e consumo da API.
*   **💻 Backend:** Responsáveis pelo servidor Node.js/Express e criação das APIs.
*   **🗄️ Banco de Dados / Dados:** Responsáveis pela modelagem dos dados e cadastramento das linhas.

---

## 🚀 Como rodar o projeto na sua máquina

Siga os passos abaixo para baixar e rodar o projeto localmente para poder programar.

### 1. Pré-requisitos
*   Node.js instalado na máquina.
*   Git instalado na máquina.

### 2. Passo a Passo
Abra o seu terminal e execute:

1. Instale as dependências (Bibliotecas do Node)
npm install

2. Inicie o servidor local
node backend/server.js

*(Observação: A integração completa do servidor será avisada no grupo quando estiver finalizada pela equipe de backend).*

---

## 📋 Regras de Trabalho (MUITO IMPORTANTE!)

Como somos 11 pessoas alterando os mesmos arquivos, **NÃO FAÇA COMMIT E PUSH DIRETO NA BRANCH `main`**. Isso vai quebrar o código de todo mundo.

Siga este fluxo para qualquer alteração que for fazer:

1. Antes de começar a programar, sempre atualize seu código local (git pull).
2. Crie uma branch (ramificação) para a sua tarefa.
3. Faça seu código, salve, e faça o commit.
4. Envie sua branch para o GitHub.
5. Crie o Pull Request (PR) e peça para alguém revisar.
